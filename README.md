# Finance Project Delivery Control Centre

**Simulated Finance Reporting Transformation | Project Data Analytics Portfolio**

## Project Overview

This project demonstrates how a Project Data Analyst can monitor and report on a finance reporting transformation programme using structured project data, delivery dashboards, dependency tracking and stakeholder reporting.

The project is a self-directed simulation, not a live organisational engagement.

## Business Problem

Finance reporting transformations require coordinated management of reporting requirements, data reconciliation, testing, defects and business sign-off.

Without centralised tracking, project stakeholders may struggle to identify delivery delays, unresolved risks and release blockers.

## Project Objectives

- Establish a centralised register of 18 project tasks.
- Track milestones, priorities, owners and dependencies.
- Monitor delivery risks and issues.
- Record UAT outcomes and defects.
- Develop a management dashboard for project visibility.
- Produce a stakeholder-facing status report.

## Tools Used

| Tool | Purpose |
|---|---|
| Google Sheets | Project registers, formulas and reporting dashboard |
| Asana | Task management, workflow status and dependencies |
| Google Docs | Weekly stakeholder status reporting |
| GitHub | Portfolio documentation and evidence |

## Project Deliverables

### 1. Project Task Register
Created an 18-task register covering requirements, data mapping, reconciliation, UAT and handover.

### 2. Delivery Dashboard
Developed a Google Sheets dashboard displaying task completion, priorities, delivery alerts, dependencies, risk exposure, UAT results and release readiness.

### 3. Risk and Issue Management
Established a register for tracking severity, ownership, mitigation actions and resolution status.

### 4. UAT and Defect Tracking
Designed UAT and defect registers to support test execution monitoring, defect prioritisation and release decisions.

### 5. Asana Workflow
Configured a task board with delivery stages and native task dependencies to demonstrate workflow coordination.

### 6. Stakeholder Reporting
Prepared a baseline project status report covering delivery progress, key risks, testing indicators and recommended management actions.

## Skills Demonstrated

Project reporting, data quality monitoring, stakeholder communication, dependency management, risk and issue tracking, UAT coordination, management information reporting and release governance.

## Project Limitations

This is a simulated project using illustrative data. No real finance system was migrated, no live production release occurred, and no actual business stakeholder approvals were obtained.
